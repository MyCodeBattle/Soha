# 52 张港式五张梭哈 (Show Hand Poker)

基于 52 张标准扑克牌的多人在线港式五张梭哈（Show Hand）网页游戏，适配桌面端与移动端浏览器。手机建议横屏使用，竖屏时会提示旋转设备。支持自建服务器部署、房间码开黑与电脑陪练。

## 核心玩法规则（完整遵循 30 条房规）

1. **基本规则**：52 张标准扑克，无大小王。每人最终获得 5 张牌（1 张暗牌 + 4 张明牌）。
2. **四轮发牌与下注**：
   - 第 1 轮：1 暗牌 + 1 明牌 → 第 1 轮下注
   - 第 2 轮：第 2 张明牌 → 第 2 轮下注
   - 第 3 轮：第 3 张明牌 → 第 3 轮下注
   - 第 4 轮：第 4 张明牌 → 第 4 轮下注
   - 摊牌 Showdown：比 5 张完整手牌
3. **话事权（先行动）**：每轮发完明牌后，由**当前公开牌面最强者**先行动。前三轮 4 张及以内牌面不计顺子和同花。若同级牌面按花色 ♠ > ♥ > ♦ > ♣ 决定行动顺序。
4. **梭哈与有效上限（Cap 规则）**：开局以参局玩家中筹码最少者的筹码量作为本局最大有效投入上限，整局单一底池，不设边池。
5. **摊牌不分花色**：最终摊牌时花色完全平等，点数牌型完全同级时平分底池。

## 项目架构

本项目采用 npm workspaces 组织：
- `packages/core`：纯 TypeScript 实现的扑克牌模型、牌型评估引擎（明牌比大小 + 摊牌比大小）以及纯函数状态机。100% 单元测试覆盖。
- `packages/server`：Node.js + Express + Socket.IO 服务端，包含房间管理、暗牌视口脱敏（`playerView`）、15s 思考倒计时、断线 30s 托管及 AI 陪练。
- `packages/client`：React 18 + Vite + Tailwind CSS + Lucide 图标 + Web Audio 原生音效引擎。支持移动端触控偷瞄底牌与响应式牌桌。

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 运行自动化测试
```bash
npm test
```

### 3. 开发模式
启动前端 Vite 开发服务器（http://localhost:3000）与后端 Socket 服务（http://localhost:3001）：
```bash
# 同时启动前后端开发服务
npm run dev
```

### 4. 生产环境构建与启动（适合服务器部署）
```bash
# 构建所有子包（前端静态资源将打包并由后端统一托管）
npm run build

# 启动单体服务器（默认端口 3001）
PORT=3001 npm run dev:server
```
打开浏览器访问 `http://<你的服务器IP>:3001` 即可开始多人对战。
